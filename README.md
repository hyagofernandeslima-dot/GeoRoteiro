# GeoRoteiro 🌎

Site de viagens pelo Brasil desenvolvido como projeto de estudo em Desenvolvimento de Sistemas.

## Sobre o projeto

O GeoRoteiro apresenta destinos brasileiros e páginas com informações para quem deseja conhecer novos lugares. Inclui página inicial, destinos, páginas dedicadas a estados, sobre nós e contato.

## Tecnologias

- HTML5
- CSS3
- JavaScript (na página de contato)
- Bootstrap (na página de destinos)

## Como executar

Abra `index.html` em um navegador ou utilize uma extensão de servidor local, como Live Server no VS Code.
